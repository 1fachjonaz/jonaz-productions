GitHub connection

The news file lives in the GitHub repository of this website. Netlify publishes every change automatically. Your token is only sent to api.github.com.

How do I get a token?

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access: only this website's repository. Permission: Contents: Read and write.
